# Design context

- Product: Rr, a production-grade Multi-Raft consensus framework for Rust.
- Audience: Rust backend engineers, distributed-systems architects, SREs, and technical evaluators.
- Brand attributes: precise, dependable, engineered, calm, modern; never playful or template-like.
- Brand capitalization: use **Rr** in prose, titles, and product references; keep lowercase `rr` only for code identifiers, crate/package names, commands, paths, and repository names.
- Visual direction: graphite/navy surfaces, warm Rust-orange accent, cool neutral text, an original consensus-ring logo and custom geometric **Rr** wordmark.
- Typography: self-hosted Inter Variable for Latin and Noto Sans SC Variable for Chinese; consistent bilingual hierarchy and comfortable long-form reading.
- Motion: subtle pointer response, consensus-line flow, scroll reveals, and reading progress; no custom cursor or motion in body copy, and full reduced-motion support.
- Experience: product-led homepage plus highly readable bilingual technical documentation; strong keyboard, mobile, dark-mode, and reduced-motion support.
- Avoid: default Docusaurus artwork, generic gradients, excessive animation, decorative glass effects in reading areas, and low-contrast muted text.
