## B. `#[non_exhaustive]` 审计

### 已落地(WS-3)

对 `crates/rr-core/src/error.rs` 的 7 个对外错误 enum 全部加注;gitnexus_impact 全 LOW(d=1 调用方 0;enum match 不被图追踪,以编译为准);跨 crate 穷尽 match 仅 `crates/rr-network/src/error_convert.rs` 7 处,各加一条不可达通配臂(映射为 sanitized `Status::internal("<category> error")`,与该模块信息防泄漏规则一致,现有行为不变)。

- [x] `RrError` / `RaftError` / `StorageError` / `ConfigError` / `RouterError` / `NetworkError` / `CodecError`。
  检查:`grep -B1 '^pub enum' crates/rr-core/src/error.rs | grep -c non_exhaustive` → 7。
  编译验证:`cargo check --workspace --all-targets --features rocks` 通过。

### 评审后**不加**(本周期结论)

- [x] `BatchOp`(rr-core/storage.rs:9)— **不加**。下游 `StorageEngine` 实现者必须 match 它实现 `write_batch`;若新增 op 时靠通配臂静默忽略 = 存储层静默丢数据,编译期硬报错反而是正确行为。
- [x] `ApplyOutcome`(rr-core/idempotency.rs:166)— **不加**。wire 级 serde enum,文档明确"dispatch 层是唯一编解码端";其演进属 wire 兼容问题,由 framing/tag(`APPLY_OUTCOME_TAG`/`APPLY_OUTCOME_VERSION`)管理,不靠源码级 non_exhaustive。

### RC 评审结论(2026-09-04 已裁决)

- [x] `DurabilityPolicy`(rr-storage/rocks.rs:46)— **不加**。match 在定义 crate 内;D 节已定 alias 于 0.3.0 拆除、届时 enum 定稿,保留穷尽 match 利于拆除时的编译强制。
- [x] `OutputTarget`(rr-core/output.rs:9)— **不加**(同 `BatchOp` 标准)。框架 dispatch(`rr-raft/output_runner`)必须穷尽 match;新增 target 时编译期硬报错优于运行期静默 `"unknown"`/Application 错误。
- [x] `IdempotencyDecision`(rr-core/idempotency.rs:94)— **不加**(同上)。跨 crate 穷尽 match 在 `rr-raft/service_adapter.rs:297-344`,是框架正确性防线;下游(Service 用户)从不接触该类型。
- [x] `PartitionConfig`(rr-core/types.rs:16)— **不加**。serde 持久化类型(A-0004 etcd schema),演进属 wire 兼容层,由 serde/版本治理(同 `ApplyOutcome` 先例)。
- [x] `RoutingTableChange`(rr-core/config.rs:13)— **不加**(同 `BatchOp` 标准)。rr-router 消费 watch 事件流,静默通配 = 路由更新停滞。
- [x] 其他 crate 的对外 pub enum 快速扫一遍。
  **已加(2026-09-04)**:`ServiceLabel`(rr-network/audit.rs)、`RaftTransport`(rr-server/config.rs)、`SecurityProtocol` + `KafkaIngestorError` + `KafkaOffsetError`(rr-ingestor-kafka)——match 均在定义 crate 内,无下游穷尽 match;两个 Kafka 错误 enum 与 WS-3 错误 enum 政策一致。
  **不加**:`GroupAction`(rr-admin,bin)/ `Command` + `StorageBackend` + `RaftTransportKind`(rr-server CLI 支撑面)、`DurabilityChoice`(与 D 节拆除时间线耦合)。
  验证:`cargo check -p rr-network -p rr-server -p rr-ingestor-kafka --features rocks` 通过。
