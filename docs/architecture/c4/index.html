C4 架构图 / C4 Architecture Diagrams

本目录用 C4 模型分层次描述 Rr：系统上下文、容器、组件，以及部署和动态视图。

This directory uses the C4 Model to describe Rr through context, container, component, deployment, and dynamic views.

阅读顺序 / Reading Order​

读者 / Audience推荐顺序 / Recommended Order
应用开发者 / Application developersContext → Containers → Dynamic: PUT Request → Dynamic: Shard Routing
框架贡献者 / Framework contributorsContainers → Components (all, including Console BFF) → Dynamic (all)
运维 / SRE / OperatorsContext → Containers → Components: Console → Deployment → Dynamic: Leader Election, Snapshot Transfer

C4 符号 / C4 Notation​

符号 / Symbol含义 / Meaning
Person人类角色 / Human actor
System软件系统的顶层抽象 / Top-level software system
Container可独立运行的部署单元 / Independently runnable unit
Component容器内的逻辑模块 / Logical module inside a container
Rel带意图和技术标注的有向关系 / Directed relationship with intent and technology

注意：C4 的 Container 不是 Docker container；它可以是一个二进制、服务器进程或加载 rr-client 的应用进程。

Note: A C4 Container is not necessarily a Docker container; it can be a binary, a server process, or an application process using rr-client.
