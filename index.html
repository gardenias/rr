共识、路由、客户端与运维共享同一套契约和集成测试。 / Consensus, routing, clients, and operations share the same contracts and integration tests.

01

内置共识能力 / Consensus, built in

运行多个相互独立的 Raft 组，获得强一致性、Leader 选举、快照与成员变更保障。 / Run multiple independent Raft groups with strong consistency, leader election, snapshots, and membership safeguards.

02

按分片扩展 / Scale by shards

将分区路由到不同 Raft 组，横向提升吞吐量，避免副本成为系统瓶颈。 / Route partitions across Raft groups and grow throughput horizontally without turning replicas into a bottleneck.

03

开箱即可运维 / Ready to operate

内置客户端重试、Prometheus 指标、结构化追踪、TLS、管理工具与部署模板。 / Ship with client retries, Prometheus metrics, structured tracing, TLS, admin tooling, and deployment templates.

04

端到端 Rust / Rust end to end

将框架嵌入你的二进制程序，通过明确的 Service 与 StateMachine trait 接入业务逻辑。 / Embed the framework in your binary and connect business logic through explicit Service and StateMachine traits.
